# 2026/11/01 基本の特徴量を hz12 と m6 にする。車体から見た前後・左右は後で試す

## Status

- accepted
- [2026/10/17 の ADR（加速度の軸の扱い）](20261017_axis_representation.md) を引き継ぐ（置き換えではない）。10.17 の「zh12」と、この ADR の「hz12」は同じもの（`e20261101_combined_eval` の `--features` の名前が `hz12`）。

## Situation

- 10.31・11.1 に、走る向きの違う場所（段差・凸凹・flat を数か所）で測った。車椅子は汎用、体重は 68〜69 kg と 51 kg の 2 人。
- スマホは車椅子の後ろに固定している。
- これまでの評価は、xyz18（世界座標系の x・y・z）を中心に、m6（合成加速度）を比べていた。

## Context

- 世界座標系の x・y は東・北なので、同じ揺れでも、走る向きで x と y の中身が変わる（10.17 の ADR）。いろいろな場所・向きのデータを使うようになったので、x・y を個別に使うのはやめたい。
- 10.17 の ADR では、前後・左右の区別を捨てる代わりに水平の大きさを使うと決め、「前後・左右を区別したほうが良いと分かったら、車体座標系への変換を検討する」としていた。その作り方の案を残しておく。

## Material for decision

- [10.31 + 11.1 を合わせた 3 クラスの評価](../knowledge/2026-11-01/20261101_combined_eval.md)（11.1。同じ人・汎用の車椅子、18 セッション）
  - hz12 は xyz18 と同じか少し良い。SVM・2.0 秒で flat / step / rough = 0.91 / 0.91 / 0.87（xyz18 は 0.91 / 0.91 / 0.86）、1.0 秒では 3 クラスとも +0.02〜0.03。どの条件でも xyz18 を下回らなかった。
  - m6 は 0.88 / 0.90 / 0.86。
- [世界座標系の x・y は、走る向きに依存するか](../knowledge/2026-10-17/20261017_heading_dependence.md)（10.17）：x・y を 90° 回すと xyz18 の精度が落ち、水平の大きさでは落ちない。水平の揺れの主軸から前後・左右を推定した軸は、水平の大きさより良くならなかった。

## Decision

1. **今後の解析の基本の特徴量は、hz12 と m6 にする。** xyz18 は、過去の結果と比べるときだけ使う。
   - hz12：z − g（鉛直）と、水平の大きさ h = √(x² + y²)。それぞれ基本4（std・range・rms・diff_max）+ 尖度・クレストで 12 個。走る向きによらない。
   - m6：合成加速度 |a| − g。同じ 6 種類。向きにも、姿勢の推定にもよらない。hz12 と比べる基準として持つ。
2. **車体から見た前後・左右の軸は、余裕が出たら試す**（今は使わない）。作り方の案：
   - スマホは車椅子に固定されているので、端末の軸は車椅子に対して動かない。重力の向き（姿勢から求める鉛直）で上下を決め、端末の前方の軸（例：端末の y 軸）を水平面に投影すると、車椅子に固定された水平の向きになる。これと、それに直交する水平の向きで、前後・左右の 2 軸を作る。
   - この 2 軸は、走る方角によらない（東西・南北に固定されない）。10.17 で試した「水平の揺れの主軸から推定する方法」と違い、揺れ方に左右されない。
   - ただし、マウントの付け方で、端末の軸と車椅子の前方はずれる（水平面内で一定の角度）。本当の前後に合わせるには、セッションごとに 1 回、向きを決める必要がある。例：付けるときに端末の向きをそろえる（マウントに印を付ける）、走り始めのまっすぐな押し出しの加速度の向きを前方とする。

## Consequences

### 良い面

- いろいろな場所・向きのデータを、同じ特徴量で学習・評価できる。
- 特徴量が 18 個から 12 個（+ 比較の 6 個）に減る。
- 車体の前後・左右を試すときの作り方を、先に決めておける。

### 受け入れたトレードオフ

- 前後の揺れと左右の揺れは、当面は区別しない（段差は前後の衝撃が大きい、などの情報は h に混ざる）。
- xyz18 で出した過去の数値（10.31 までの評価、発表資料）とは、特徴量が違う。比べるときは同じ条件で計算し直す。

### 今後、見直す条件

- hz12 で step と rough の取り違えが減らず、前後・左右の違い（段差は前後、凸凹は上下・左右）が効きそうなときは、2 の車体の前後・左右を試す。

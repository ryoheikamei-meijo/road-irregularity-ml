# YYYY/MM/DD タイトル

## Status

- proposed / accepted / rejected / deprecated / superseded
  （superseded の場合は後継 ADR へのリンクを書く）

## Situation

- 決定時のチームの状況や制約。

## Context

- 決定が必要になった動機や理由。

## Material for decision

- 決定時に参照した材料（記事・比較資料・ベンチマークなど）。

## Decision

- 決定内容と、その理由。

## Consequences

- 決定によって生じる結果。良い面と、受け入れたトレードオフの両方を書く。

# 重りを足した測定の計画（core5b が重さの違いに強いかを確かめる）

[体重・車椅子によらない周波数帯の特徴量](../2026-11-01/20261101_band_features.md) で、上下の揺れを 8〜16 Hz に絞った特徴量（core5b）にすると、51 kg → 68〜69 kg の rough が 0.89 → 0.97 に上がった。ただし、人が 2 人だけで、改善が見えたのは 1 方向・1 回の評価だけ。帯域も、テストと同じデータを見て選んだ。そのため、**core5b が本当に効いているかは、まだ言えない**。

体重の違う人を多く集めるのは難しいので、**同じ人に重りを足して**、重さの違いへの強さを確かめる。

## まとめ

- **2 人 × 重り 3 段階（0・+10・+20 kg）**で、同じコース（11.1 と同じ場所）を走る。51 kg の人 + 20 kg ≒ 69 kg の人になるので、「同じ重さで人だけ違う」組も作れる。
- 余裕があれば、**実際に重い人（80 kg 以上）を 1 人**加える。
- **帯域（8〜16 Hz）・特徴量・評価のしかた・成功の基準は、測定の前にこのメモで決めておき、データを見てから変えない**。変えた場合は「探索的な結果」として分けて書く。
- 言えるようになるのは「**重さ（総重量）の違いに強い**」まで。「体重の違う人に強い」とは言い切れない（体の柔らかさ・重心・乗り方は、重りでは再現できないため）。

## 1. 目的

1. 重さを変えても、8〜16 Hz の上下の揺れがほぼ変わらず、固有振動数の帯域（15〜30 Hz）だけが変わるかを確かめる（仕組みの確認）。
2. 重さの違う条件で学習・テストしたとき、core5b が core5 より強いかを確かめる（精度の確認）。
3. 同じ重さで人だけが違う組を比べ、「重さの効果」と「人の違い」を分ける。

## 2. 重りと、体重の違う人の違い

| | 重りを足す（同じ人） | 体重の違う人を集める |
| --- | --- | --- |
| 変わるもの | 重さだけ | 重さ ＋ 体格・座り方・漕ぎ方・速度の癖など |
| 分かること | 重さが変わっても効くかを、ほかの違いを混ぜずに確かめられる | 実際に使う場面（いろいろな人）で効くか |
| 必要な人数 | 2〜3 人 | 6 人以上 |
| 段階 | 同じ人で何段階でも試せる | 来てくれた人の体重だけ |

重りでは確かめられないこと：

- **体の柔らかさ**：人の体は揺れを吸収するクッションになる（体が揺れやすい速さは 4〜6 Hz と言われる）。砂袋は同じ重さでも吸収のしかたが違う。重りの入ったベストなど、体に密着するもののほうが本物の体重に近い。
- **重心の位置**：重い人は重さが体全体に分かれるが、重りは 1 か所に集まる。置き場所で前輪・後輪にかかる重さの割合が変わり、段差で前輪が持ち上がる様子（傾き）に影響する。
- **人ごとの乗り方**：重い人の漕ぎ方・速さの違いは再現できない。

## 3. 測定の組み合わせ

| 人 | 0 kg | +10 kg | +20 kg |
| --- | --- | --- | --- |
| 51 kg の人 | 51 | 61 | **71** |
| 69 kg の人 | 69 | 79 | **89** |

- 51 kg の人 + 20 kg（71 kg）と、69 kg の人 + 0 kg（69 kg）が、ほぼ同じ重さで人だけが違う組になる。
- 69 kg の人 + 20 kg（89 kg）で、今いちばん弱い「重いほう」（重い人は凸凹の揺れが小さく、flat に近づく）を確かめる。
- 余裕があれば、実際に重い人（80 kg 以上）を 1 人、重りなしで同じコースを走ってもらう。重りで確かめたことが、本物の重い人でも成り立つかの確認になる。

## 4. コースと手順

### 場所（11.1 と同じ。GPS の中央値）

| 場所 | 11.1 のセッション | 緯度, 経度 |
| --- | --- | --- |
| flat ①（基準の平坦路） | `20261101141139` | 34.999860, 137.073717 |
| 段差 ① | `20261101140355` | 35.000091, 137.074409 |
| 段差 ② | `20261101142036` | 35.000146, 137.073513 |
| 凸凹 ① | `20261101141512` | 35.000178, 137.073555 |
| 凸凹 ② | `20261101142926` | 35.000097, 137.072020 |

（GPS の誤差は 5〜8 m。場所の番号は [体重の違う人への汎化](../2026-11-01/20261101_weight_transfer.md) の 2 章と同じ。）

### 1 人・1 段階の重りあたりのセッション

| 種類 | 場所 | 内容 | 時間の目安 |
| --- | --- | --- | --- |
| flat | flat ① | 60 秒、ふつうの速さで走る（ボタンなし） | 1 分 |
| 段差 | 段差 ①・② | 各場所で、上り 10 回・下り 10 回 | 各 2〜3 分 |
| 凸凹 | 凸凹 ①・② | 各場所で 10 回 | 各 2 分 |

- 1 人・1 段階で 5 セッション、約 10〜12 分。2 人 × 3 段階で 30 セッション、約 1 時間（重りの付け替え・移動を除く）。
- **同じ場所では、重りの段階を続けて測る**（時間を空けると、路面の濡れ具合などが変わるため）。例：段差 ① で 0 kg → +20 kg → +10 kg と続けて測ってから、段差 ② に移る。
- **重りの順番は、人によって変える**（疲れ・慣れの影響を、重さの影響と混ぜないため）。例：51 kg の人は 0 → +20 → +10、69 kg の人は +10 → 0 → +20。
- 余裕があれば、**最後にもう一度 0 kg で flat ① を走る**（最初の 0 kg と比べて、時間による変化が無いかを確かめる）。

### 記録すること

| 項目 | 記録のしかた |
| --- | --- |
| 本人の体重 | アプリの体重の欄（本人の体重のまま。重りは足さない） |
| 重り | アプリのメモの欄に「重り 10kg 膝」のように、重さと置き場所を書く |
| 漕ぎ方 | 自分で漕いだか、押してもらったか（押した人も）。**押す人は全員同じにする**のが望ましい |
| 速さ | ふつうの速さで走る。GPS は自動で記録される |
| 重りの種類 | 砂袋・ベストなど |

解析では、`configs/sessions/<日>.csv` に `load_kg`（重り）の列を足し、`weight_kg` は本人の体重のままにする。

## 5. 安全面

- **車椅子の最大の積載重量を確認する**（汎用の車椅子は 100 kg 前後が多い。本体のラベルに書いてある）。69 kg + 20 kg = 89 kg が収まるか。
- **重りは低く、真ん中に置く**（膝の上、座面の下）。**背もたれに掛けない**（重心が後ろに上がり、段差を上るときに後ろに転びやすい）。
- 段差では、補助の人がそばにつく。
- 重りを足すと漕ぐのが重くなるので、無理のない段階までにする。

## 6. 評価のしかた（測定の前に決めておく）

### 固定すること

| 項目 | 内容 |
| --- | --- |
| 帯域 | **8〜16 Hz**（バターワース 4 次・ゼロ位相）。新しいデータを見てから変えない |
| 特徴量 | core5（z_rms・z_kurt・tilt_range・g_low_high・g_over_z）と core5b（zb_rms・zb_kurt・tilt_range・g_low_high・g_over_z）を比べる |
| モデル | SVM（標準化 + RBF、C = 1、`class_weight="balanced"`）。チューニングしない |
| ラベル | 方針A、START を 1 秒ずらす |
| 窓 | 2.0 秒を主に、1.0 秒を参考に |
| 指標 | クラスごとの再現率 |

### 評価 1：仕組みの確認（帯域ごとの比）

- 人ごと・場所ごとに、重りありのセッションと 0 kg のセッションで、帯域ごとの上下の揺れの振幅の比を出す（[帯域の特徴量](../2026-11-01/20261101_band_features.md) の 1 章と同じ方法）。
- **成功の基準**：8〜16 Hz の比が 0.8〜1.25 に収まる組が 8 割以上。かつ、15〜30 Hz の比が、重さに応じて変わる（重いほど小さくなる）。

### 評価 2：重さを変えた学習・テスト

- 人ごとに、0 kg で学習 → +20 kg でテスト、+20 kg で学習 → 0 kg でテスト。2 人分を合わせても集計する。
- 10.31・11.1 のデータで学習 → 新しいデータ（全段階）でテストも行う。
- **成功の基準**：core5b のクラスごとの再現率の最低値が、core5 以上。かつ、core5b は、同じ重さの中で学習・テストしたとき（セッション単位の LOGO）からの下がり幅が 0.03 以内。

### 評価 3：同じ重さで人だけが違う組

- 51 kg の人 + 20 kg（71 kg）と、69 kg の人 + 0 kg（69 kg）を、評価 1 と同じ方法で比べる。
- 比が 1 に近ければ、これまでの 51 kg と 69 kg の差は、主に重さによるものだったと言える。1 から離れていれば、人の違い（乗り方・漕ぎ方など）も効いている。

### 評価 4：重い人（加えた場合）

- これまでのデータと重りのデータで学習 → 重い人でテスト。core5 と core5b を比べる。

### 結果の書き方

- 評価 1〜3 は、成功の基準を満たしたか・満たさなかったかを、そのまま書く。満たさなかった場合も書く。
- データを見てから帯域・特徴量・基準を変えた場合は、「探索的な結果」として分けて書く。

## 7. 言えること・言えないこと

| 結果 | 言えること |
| --- | --- |
| 評価 1・2 が成功 | 「上下の揺れを固有振動数より下の帯域に絞ると、総重量（51〜89 kg）の違いに強くなる」 |
| 評価 3 で比が 1 に近い | 「51 kg と 69 kg の人の差は、主に重さによるもの」 |
| 評価 4 も成功 | 「実際の重い人でも成り立つ」 |

- どの場合も、**汎用の車椅子・同じコース・ふつうの速さ**での結果。車椅子・速度・場所が変わったときは、別に確かめる必要がある。
- 2〜3 人なので、統計の検定（人ごとの差の検定）までは言えない。人ごと・場所ごとの結果がそろっているか（一貫性）で示す。

# 10.31 + 11.1 を合わせた 3 クラスの評価（同じ人・汎用の車椅子）

10.31（汎用の車椅子）と 11.1 の、同じ人（68〜69 kg、測定者本人）のデータを合わせて、flat / step / rough の 3 クラスを評価し直した。flat のセッションが 2 → 6 に増えた。

## サマリ

- **flat が大きく上がった**（SVM・2.0 秒・xyz18 で 0.49 → **0.91**）。flat のセッションが 6 つになり、揺れの大きい flat（`20261031150048`）を当てられるようになった（0.26 → 0.88）。10.31 だけでは、flat の種類が足りなかったことが確認できた。
- **3 クラスとも 0.86〜0.91**（SVM・2.0 秒・xyz18：flat 0.91 / step 0.91 / rough 0.86）。m6 は 0.88 / 0.90 / 0.86。
- 11.1 のボタンのラグも、10.31 とほぼ同じ（START から揺れ始めまで、中央値 1.05〜1.40 秒）。両日とも、ラベルの始まりを 1 秒ずらした（shift_1）。ずらさない場合も 0.90 / 0.89 / 0.84 で、差は小さい。
- **x・y を合成した水平の大きさ h と z（hz12）でも評価した**。xyz18 と同じか少し良い（SVM・2.0 秒：0.91 / 0.91 / 0.87、1.0 秒では 3 クラスとも +0.02〜0.03）。特徴量が 12 個で走る向きにもよらないので、今後の基本にするのがよい。
- 11.1 は、10.31 より step・rough が少し低い（step 0.88 と 0.92、rough 0.82 と 0.93）。rough は `20261101143126`（0.73）、step は `20261101142339`（0.81）が低い。

### 水平の大きさ h と z（hz12）

x と y を合成して水平の大きさ h = √(x² + y²) にし、h と z の 2 軸 × 6 種類 = 12 個の特徴量にした（[ADR 2026-10-17](../../adr/20261017_axis_representation.md) の軸の表し方。h は `features.horizontal_axes` と同じ定義）。他の条件は同じ（shift_1）。

- **hz12 は xyz18 と同じか、少し良い**。2.0 秒・SVM ではほぼ同じ（rough +0.01）。1.0 秒・SVM では 3 クラスとも +0.02〜0.03、RF では flat が +0.04（2.0 秒）。差は小さく、各設定 1 回の評価なので誤差の範囲も含むが、向きはそろっている。
- 特徴量は 18 → 12 個に減り、走る向きにも依存しない。今後の基本の特徴量セットは hz12 がよい。
- セッションごとでは、step の `20261031152930`（0.82 → 0.88）・`20261101142339`（0.81 → 0.86）が上がり、`20261031145759`（0.92 → 0.86）が下がった。

### 間違いの内訳（hz12・SVM・2.0 秒。その場で集計）

間違いは 1713 窓中 164 窓（m6 は 205 窓）。

| 間違い | 窓数 | 主なセッション | 間違えた窓の特徴（中央値） |
| --- | --- | --- | --- |
| **flat → rough** | **48** | `20261031150048`（23）、`20261101143455`（17） | z の rms 5.66・h の rms 7.20 で、rough の正解の窓（6.06・9.92）に近い。z の尖度 0.46 と低い（揺れが続く形） |
| **rough → step** | **39** | `20261101143126`（20）、`20261101141730`（10）、`20261031145017`（8） | z の尖度 5.04（rough の正解は 1.59）。凸凹の中に単発の大きな衝撃がある |
| **step → rough** | **30** | `20261101142339`（10）、`20261031152930`（9）、`20261031145759`（6） | z の尖度 4.11（step の正解は 8.80）。衝撃のあとに揺れが続き、単発に見えない |
| flat → step | 24 | 4 つの flat に分散 | z の尖度 3.66・h の尖度 13.45。平坦路の中の単発の段差（継ぎ目など） |
| rough → flat | 13 | `20261101143126`（10） | z の rms 2.20。通過の終わり 20% に多い（8 窓） |
| step → flat | 10 | `20261031145759`（6）、`20261031152930`（4） | |

- **step・rough・flat の区別は、主に「揺れの大きさ（rms）」と「単発の衝撃か、続く揺れか（尖度）」で決まっている**。間違いの多くは、この 2 つが別のクラスに似ている窓。
  - 揺れの大きい flat（粗い舗装）は、rough と区別できない（flat → rough）。
  - 単発の衝撃が混ざる凸凹は step に、衝撃のあとに揺れが続く段差は rough に見える（rough ↔ step）。10.17 の step → rough、10.31 の `20261031150809` と同じ形。
- **rough の間違いの 6 割（52 窓中 30）は `20261101143126` の 1 セッション**（場所 D の凸凹、再現率 0.75）。単発の衝撃が混ざる凸凹で、10.31 で除いた `20261031150809` と似ている。
- 段差の `20261101142339`（場所 C）は、GPS では凸凹 C とほぼ同じ場所。段差の前後の路面が粗い可能性がある（未確認）。
- 通過の中の位置では、rough の終わり 20% の間違いが多い（81 窓中 17。中 60% は 247 窓中 27）。揺れの終わりから STOP までの走行が残っているため（[ボタンのラグ](../2026-10-31/20261031_button_lag_eval.md) の 2 章と同じ）。step は位置による差が小さい。
- 段差の上り・下りでは、間違いの割合はほぼ同じ（下り 8%、上り・乗り越えた 10%）。
- m6 は、揺れの大きい flat（`20261031150048`）を rough と間違える窓が多い（61 窓。hz12 は 23）。水平と鉛直を分けたほうが、この flat を区別しやすい。

## 2. 考察

- 10.31 だけでは flat が 0.49 しかなかったのは、flat のセッションが 2 つで、しかも性質が違ったため（[ボタンのラグ](../2026-10-31/20261031_button_lag_eval.md) の 3 章）。flat を 6 セッションに増やすと、セッション単位の LOGO でも 0.91 になる。**flat はデータの種類を増やせば当てられる**。
- 残る間違いは、主に step ↔ rough と flat → rough。rough の低い `20261101143126` は、場所 D（11.1 で A から西に約 220 m）の凸凹。

## 3. 限界

- 同じ人（68〜69 kg）・同じ車椅子（汎用）だけ。体重の違う人（51 kg）は入れていない。
- 各設定 1 回の評価。

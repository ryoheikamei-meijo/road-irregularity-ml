# ジャイロの特徴量を足す（10.31 + 11.1）

加速度の特徴量（hz12・m6）だけでは、段差と凸凹の取り違えが残っていた（「単発の衝撃か、続く揺れか」で見分けているため。[10.31 + 11.1 の評価](20261101_combined_eval.md) の間違いの内訳）。車体が実際に傾いたかを表すジャイロの特徴量を足した。

## サマリ

- **傾いた角度の変化（tilt2）が大きく効く**。hz12 に足すと、SVM・2.0 秒で flat / step / rough = 0.91 / 0.91 / 0.87 → **0.95 / 0.96 / 0.94**（tilt2 + ratio2 の 4 個を足しただけ）。段差 ↔ 凸凹の取り違えは 69 窓 → 25 窓。
- 窓の中で傾きが変わる範囲（中央値、2.0 秒）は、**step 7.3 度、rough 3.0 度、flat 1.2 度**で、はっきり分かれる。セッションごとでも、step 3.9〜9.4 度、rough 2.6〜3.7 度、flat 0.9〜1.4 度で、日・場所によらずそろっている。
- **日を丸ごと分けても効く**（10.31 で学習 → 11.1 でテスト、とその逆）。hz12 だけでは、10.31 → 11.1 の rough が 0.69、11.1 → 10.31 の step が 0.74 まで落ちるが、tilt2 + ratio2 を足すと、どちらの向きでも 0.92〜0.98。場所の地形を覚えているのではなく、段差で車体が傾くことを捉えていると考えられる。
- 傾きの速さ（g6）だけを足しても、少ししか上がらない（rough 0.87 → 0.89）。g6 は tilt2・ratio2 があれば無くてもよい。
- 曲がる速さ（yaw6）を足すと、flat が少し下がる（0.95 → 0.94、flat → rough が 22 → 35）。使わない。
- 16 個は多いので、**5 個（core5）に絞った**：z の rms・z の尖度・傾きの範囲・g の低 ÷ 高・g ÷ z。SVM・2.0 秒で 0.95 / 0.95 / 0.94 と、16 個（0.95 / 0.96 / 0.94）とほぼ同じ。日を分けた評価でも 0.93〜0.97 で落ちない。h（水平の大きさ）の特徴量は、全部外しても下がらなかった。**今後の基本は core5**（4 章）。
- m6 にも同じように効く（m6 + g6 + tilt2 + ratio2 で 0.95 / 0.95 / 0.93）。

## 0. 方法

`src/experiments/e20261101_gyro_features.py`。

### ジャイロの扱い

- `gyro.csv`（端末の座標系の角速度）を、`acc.csv` の姿勢（rotation vector）で世界座標系に変換した。姿勢は、センサーの時刻（`eventTimestampNs`）が一番近い加速度の行のものを使い、加速度の行の時刻に補間した。
- 走る向きによらない 2 つの量に分けた（[ADR 2026-10-17](../../adr/20261017_axis_representation.md)・[2026-11-01](../../adr/20261101_feature_sets_hz_m6.md) と同じ考え方）。
  - **g（傾きの速さ）**：水平の角速度の大きさ √(ωx² + ωy²)。車体が前後・左右に傾く速さ。
  - **w（向きを変える速さ）**：鉛直の角速度 ωz。曲がる速さ。
- **傾き**：端末の座標系での鉛直の向きが、そのセッションの中央値からどれだけずれたか（度）。車椅子が前後・左右にどれだけ傾いているか。

### 特徴量

| 名前 | 個数 | 内容 |
| --- | --- | --- |
| g6 | 6 | g × 基本4（std・range・rms・diff_max）+ 尖度・クレスト |
| tilt2 | 2 | 窓の中の傾きの範囲（最大 − 最小）、標準偏差 |
| ratio2 | 2 | g の低い周波数（5 Hz 未満）÷ 高い周波数（10 Hz 超）のパワー（log10）、g の rms ÷ z の rms（log10） |
| yaw6 | 6 | 鉛直の角速度 ωz × 基本4 + 尖度・クレスト（参考。今はスクリプトから外した） |

### 条件

[10.31 + 11.1 の評価](20261101_combined_eval.md) と同じ。10.31（汎用の車椅子）と 11.1 の 68〜69 kg の人の 18 セッション、方針A、START を 1 秒ずらす、SVM・RF、セッション単位の LOGO、窓 1.0・2.0 秒。指標はクラスごとの再現率。

## 1. 結果

### クラスごとの値（中央値、2.0 秒）

| クラス | g の rms [rad/s] | g の尖度 | 傾きの範囲 [度] | g の低 ÷ 高（log10） | g ÷ z（log10） |
| --- | --- | --- | --- | --- | --- |
| step | 0.91 | 14.8 | **7.3** | −0.03 | −0.82 |
| rough | 0.87 | 3.8 | **3.0** | −0.61 | −0.84 |
| flat | 0.33 | 0.9 | **1.2** | −0.79 | −0.98 |

- 段差は「ゆっくり大きく傾く」（傾きの範囲が大きく、低い周波数が多い）。凸凹は「傾きの速さは段差と同じくらいだが、細かく揺れるだけで、傾きの範囲は小さい」。予想どおり。

## 2. 考察

- 加速度だけでは、「衝撃が混ざる凸凹」と「揺れが長引く段差」を見分けられなかった。**車体の傾き**は、段差では前輪が持ち上がる・落ちるので大きく、凸凹では細かく揺れるだけで小さい。加速度とは別の手がかりになっている。
- 日を分けても効くので、場所の坂などを覚えているわけではないと考えられる。ただし、2 日・数か所のデータなので、坂道の上の凸凹や、低い段差では、傾きの範囲が重なる可能性がある（段差の `20261031142102` は 3.9 度で、凸凹の上限 3.7 度に近い）。
- 傾きの範囲や比は、揺れの大きさ（振幅）ではなく角度の変化や比なので、体重・速度の違いにも強い可能性がある（[補正の案](20261101_normalization_ideas.md) の B「軸どうしの比」にあたる）。51 kg の人のデータで確かめる。

## 3. 限界

- 傾きの基準は、そのセッション全体の姿勢の中央値。実際に使うときは、走りながら更新する基準（直前の数十秒の中央値など）にする必要がある。
- 姿勢（rotation vector）の精度に依存する。地磁気を使うので、車椅子の鉄のフレームの影響を受ける可能性がある（傾きは主に重力と角速度から決まるので、影響は小さいと考えている。未確認）。
- ジャイロは 10.31 以降のデータにしか無い。
- 各設定 1 回の評価。日を分けた評価は、各向き 1 回。

## 4. 特徴量を絞る

16 個（hz12 + tilt2 + ratio2）から、1 個ずつ外したときに 3 クラスの再現率の平均が一番高くなるものを外していった（SVM・2.0 秒。その場で集計）。

| 個数 | flat / step / rough | 外したもの |
| --- | --- | --- |
| 16 | 0.95 / 0.96 / 0.94 | |
| 13 | 0.96 / 0.96 / 0.95 | z_crest、h_range、z_range |
| 8 | 0.96 / 0.96 / 0.94 | z_std、h_diff_max、h_kurt、h_rms、tilt_std |
| 6 | 0.96 / 0.96 / 0.94 | z_diff_max、h_std |
| **5** | **0.95 / 0.95 / 0.94** | h_crest |
| 4 | 0.92 / 0.95 / 0.91 | z_kurt |
| 3 | 0.94 / 0.89 / 0.88 | z_rms |

5 個までは、ほとんど下がらない。それより減らすと下がる。残った 5 個（**core5**）：

| 特徴量 | 何を表すか |
| --- | --- |
| z_rms | 上下の揺れの大きさ（flat と、step・rough を分ける） |
| z_kurt | 単発の衝撃か、続く揺れか |
| tilt_range | 窓の中で車体が傾いた角度の範囲（段差で大きい） |
| g_low_high | 傾きの速さの、ゆっくり ÷ 速い（段差はゆっくり大きく傾く） |
| g_over_z | 傾きの速さ ÷ 上下の揺れ |

候補の比較（その場で集計。core5 はスクリプトにも入れた）：

| 特徴量 | 個数 | SVM 2.0 秒 | 段差 ↔ 凸凹 | RF 2.0 秒 | SVM 1.0 秒 | 10.31 → 11.1 | 11.1 → 10.31 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| hz12 | 12 | 0.91 / 0.91 / 0.87 | 69 | 0.94 / 0.90 / 0.81 | 0.90 / 0.83 / 0.81 | 0.90 / 0.91 / 0.69 | 0.99 / 0.74 / 0.93 |
| hz12 + tilt2 + ratio2 | 16 | 0.95 / 0.96 / 0.94 | 25 | 0.95 / 0.95 / 0.82 | 0.92 / 0.89 / 0.86 | 0.92 / 0.95 / 0.93 | 0.98 / 0.96 / 0.94 |
| core5 + h_crest | 6 | 0.96 / 0.96 / 0.94 | 30 | 0.95 / 0.94 / 0.82 | 0.92 / 0.88 / 0.85 | 0.94 / 0.94 / 0.96 | 0.97 / 0.97 / 0.95 |
| **core5** | **5** | **0.95 / 0.95 / 0.94** | **33** | 0.95 / 0.94 / 0.80 | 0.92 / 0.88 / 0.84 | **0.93 / 0.95 / 0.97** | **0.97 / 0.96 / 0.94** |
| core5 − g_low_high | 4 | 0.95 / 0.92 / 0.89 | 63 | 0.95 / 0.91 / 0.80 | 0.92 / 0.85 / 0.83 | 0.92 / 0.98 / 0.82 | 0.98 / 0.88 / 0.94 |
| core5 − g_over_z | 4 | 0.87 / 0.96 / 0.88 | 27 | 0.88 / 0.95 / 0.79 | 0.87 / 0.87 / 0.82 | 0.96 / 0.92 / 0.80 | 0.80 / 0.97 / 0.95 |

- core5 は 16 個とほぼ同じで、日を分けても落ちない。段差 ↔ 凸凹の取り違えは 25 → 33 窓と少し増えるが、hz12 の 69 窓よりずっと少ない。1.0 秒では 16 個より 0.01〜0.02 低い。
- ジャイロの 3 個は、どれを外しても下がる。g_low_high を外すと段差 ↔ 凸凹が増え、g_over_z を外すと flat が下がる。
- **h（水平の大きさ）は残らなかった**。水平の揺れの情報は、傾き（ジャイロ）の特徴量でほぼ代わりになっていると考えられる。ADR 2026-11-01 の hz12 は、加速度だけで比べるときの基本として残す。
- 1 個ずつ外す方法は、この 18 セッションで一番良いものを選んでいるので、少し楽観的。体重の違う人のデータなど、別のデータでも確かめる。

## 5. 再現方法

```bash
python -m src.experiments.e20261101_gyro_features
```

出力は `data/analysis/20261101_gyro_features/`（`results.csv`、`confusion.csv`）。日を分けた評価と、特徴量を絞る手順は、その場で集計した。yaw6 は、絞り込みのときにスクリプトから外した（1 章の yaw6 の行は、外す前に出した値）。

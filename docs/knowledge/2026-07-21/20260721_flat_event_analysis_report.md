# flat・step・rough の鉛直加速度分析報告書

## 1. 目的

本分析の目的は、車椅子に取り付けたスマートフォンで取得した加速度データについて、次の仮説を既存データから検証することである。

1. `step` または `rough` が発生した区間では、`flat` より鉛直方向加速度の変動が大きい。
2. `z_std`、`z_range`、`z_rms`、`z_diff_max` の基本特徴量には、`flat` と `event` を分ける傾向が現れる。
3. `step` と `rough` は振幅だけでは重なりやすく、単一の1秒窓では安定した識別が難しい。

ここで、`event = step + rough` と定義する。元データおよび既存コード内の `dansa` は `step`、`dekobo` は `rough` と読み替え、以後の結果では `flat`、`step`、`rough` の表記を使用する。

## 2. 使用データ

### 2.1 対象

- `wheelchair_data/6.22`: 有効な11走行
- `wheelchair_data/7.12`: 51 kgかつ有効な11走行
- 合計: 22走行

7月収集分については、操作失敗、イベント終了マーカー欠落、71 kgの走行を除外した。71 kgのデータは条件の異なる有効データではあるが、同条件のサンプルが不足しているため今回の比較には含めていない。

### 2.2 前処理とラベル付け

- 対象信号: 世界座標系鉛直加速度 `accWorldZ` から重力加速度 `9.80665 m/s²` を引いた `world_z_linear`
- 窓幅: 1.0秒
- ストライド: 0.25秒
- サンプリング間隔: 約0.25秒（1窓あたり約4点）
- イベント開始時刻: 0.5秒前方へ拡張
- ラベル条件: 1秒窓とイベント区間の重なり率が50%以上
- ラベル優先順位: `step > rough > flat`

### 2.3 窓数

| ラベル | 窓数 | 全体に占める割合 |
| --- | ---: | ---: |
| `flat` | 4,102 | 88.8% |
| `step` | 93 | 2.0% |
| `rough` | 422 | 9.1% |
| 合計 | 4,617 | 100.0% |

`event` 515窓のうち422窓、約82%が `rough` である。このため、`flat vs event` の集計結果は `rough` の分布を強く反映することに注意が必要である。

## 3. 分析方法

### 3.1 波形の確認

`flat`、`step`、`rough` からそれぞれ3窓を選び、対象となる1秒窓と前後約1秒を含む鉛直加速度波形を同一の時間軸・縦軸で比較した。極端な波形だけを恣意的に選ばないよう、各クラスの `z_std` の25%、50%、75%分位点に近い窓を代表例とした。

![代表的な鉛直加速度波形](../../../data/analysis/20260721_flat_event/figures/representative_waveforms.png)

### 3.2 特徴量分布

次の4特徴量について、3クラス比較と `flat vs event` 比較を行った。

- `z_std`: 1秒窓内の鉛直加速度の標準偏差
- `z_range`: 1秒窓内の最大値と最小値の差
- `z_rms`: 1秒窓内の鉛直加速度のRMS
- `z_diff_max`: 隣接サンプル間の最大変化量

![flat・step・rough の特徴量分布](../../../data/analysis/20260721_flat_event/figures/three_class_feature_distributions.png)

![flat と event の特徴量分布](../../../data/analysis/20260721_flat_event/figures/feature_distributions.png)

### 3.3 分離傾向の定量化

単一特徴量の分離傾向はAUCで確認した。AUCは、比較する2クラスから1窓ずつ無作為に選んだとき、値の大小関係を正しく並べられる確率に相当する。0.5は大小関係に識別情報がない状態、1.0は完全に分離している状態を表し、分類精度そのものではない。

4特徴量をまとめて使った場合は、ロジスティック回帰およびRBF-SVMを用いた。スライディング窓の重複による情報漏洩を避けるため、同一走行の窓が学習側と評価側に分かれないよう、走行IDをグループとした5分割交差検証を用いた。クラス不均衡が大きいため、通常のaccuracyではなく各クラスのrecallを平均したbalanced accuracyも確認した。

## 4. 結果

### 4.1 3クラスの基本特徴量

各クラスの中央値は、4特徴量すべてで `flat < step < rough` となった。

| 特徴量 | `flat` 中央値 | `step` 中央値 | `rough` 中央値 |
| --- | ---: | ---: | ---: |
| `z_std` | 4.58 | 6.70 | 9.67 |
| `z_range` | 11.80 | 17.56 | 24.99 |
| `z_rms` | 5.64 | 7.88 | 11.55 |
| `z_diff_max` | 7.50 | 9.89 | 15.02 |

平均的にはイベント側ほど鉛直加速度の変動が大きく、特に `rough` で大きい。一方、箱ひげ図では各クラスの分布が重なっており、中央値の差だけで個々の1秒窓を安定して分類できるとは限らない。

同じ走行内で各クラスの中央値を比較したところ、`rough` が `flat` より大きかったのは13走行中11走行だった。これに対し、`step` が `flat` より大きかったのは8走行中5走行であり、`step` の振幅増加は走行間で一貫していなかった。

### 4.2 `flat vs event` の比較

`flat` と `event` の中央値には明確な差が見られた。

| 特徴量 | `flat` 中央値 | `event` 中央値 | `event` を高値としたAUC |
| --- | ---: | ---: | ---: |
| `z_std` | 4.58 | 8.98 | 0.746 |
| `z_range` | 11.80 | 23.52 | 0.746 |
| `z_rms` | 5.64 | 11.09 | 0.789 |
| `z_diff_max` | 7.50 | 14.23 | 0.672 |

`z_rms` が最も強い分離傾向を示し、`z_std` と `z_range` がそれに続いた。したがって、基本特徴量に `flat vs event` の分離傾向があるという仮説は、記述統計上は支持される。

ただし、4特徴量を使った走行単位交差検証のbalanced accuracyは、ロジスティック回帰で0.716、RBF-SVMで0.719だった。完全な分離には至っていない。

さらに、二値分類で `event` と判定できた割合を元のイベント種別ごとに確認すると、次の差があった。

| モデル | `flat` を正しくflatと判定 | `step` をeventと判定 | `rough` をeventと判定 |
| --- | ---: | ---: | ---: |
| ロジスティック回帰 | 0.757 | 0.441 | 0.727 |
| RBF-SVM | 0.801 | 0.430 | 0.682 |

`rough` は約68〜73%をeventとして検出できたが、`step` は約43〜44%しか検出できなかった。したがって、`flat vs event` の全体的な分離傾向を、そのまま「stepとroughの両方を検出できる」と解釈してはならない。

### 4.3 クラス対ごとの比較

| 比較 | 最良の単一特徴量AUC | 4特徴量を用いたbalanced accuracy |
| --- | ---: | ---: |
| `flat vs step` | 0.694 (`z_rms`) | 0.503〜0.609 |
| `flat vs rough` | 0.810 (`z_rms`) | 0.738〜0.744 |
| `step vs rough` | 0.640 (`z_rms`) | 0.588〜0.611 |

現在の基本特徴量が最も捉えられているのは `flat vs rough` である。`flat vs step` と `step vs rough` はどちらも弱く、現在の特徴量構成では `step` が主要なボトルネックになっている。

### 4.4 収集日別の再現性

`z_rms` の中央値は両収集日で同じ順序を示した。

| 収集日 | `flat` | `step` | `rough` |
| --- | ---: | ---: | ---: |
| 6/22 | 5.34 | 7.34 | 11.30 |
| 7/12 | 6.77 | 9.10 | 13.43 |

`flat < step < rough` という傾向自体は収集日を変えても確認できた。一方、7月データの `rough` は2イベントだけであり、収集日をまたいだ再現性を強く結論づけるにはサンプルが不足している。

### 4.5 `step vs rough` をイベント単位で見た結果

単一の1秒窓ではなく、同じイベントに属する複数窓の中央値を使うと、`step vs rough` のAUCは特徴量に応じて0.708〜0.731となった。窓単位のAUC 0.566〜0.640より高く、時間方向に情報をまとめることで分離傾向が強くなる可能性がある。

イベント継続時間にも差が見られた。

| ラベル | イベント数 | 継続時間中央値 | 最短 | 最長 |
| --- | ---: | ---: | ---: | ---: |
| `step` | 9 | 2.80秒 | 1.51秒 | 3.57秒 |
| `rough` | 19 | 5.88秒 | 1.01秒 | 11.88秒 |

中央値では `rough` の方が長いが、最短・最長範囲には重なりがある。そのため継続時間だけを固定しきい値で分類するのではなく、振幅と継続時間を組み合わせて検証する必要がある。

### 4.6 特徴量間の冗長性

特徴量間のSpearman順位相関は次の通りだった。

| 特徴量の組合せ | 相関係数 |
| --- | ---: |
| `z_std` と `z_range` | 0.996 |
| `z_std` と `z_rms` | 0.915 |
| `z_range` と `z_rms` | 0.910 |
| `z_std` と `z_diff_max` | 0.724 |

`z_std`、`z_range`、`z_rms` は強く相関しており、4特徴量のうち複数が同じ振幅情報を表している。特徴量数が4個あっても、4種類の独立した判別材料が存在するわけではない。

## 5. 仮説に対する判断

| 仮説 | 判断 | データから読み取れること |
| --- | --- | --- |
| イベントはflatより鉛直加速度の変動が大きい | 条件付きで支持 | `rough` では一貫した差がある。`step` は中央値がflatより高いが、走行間で一貫しない。 |
| 基本特徴量でflatとeventに分離傾向が現れる | 部分的に支持 | 全体AUCは最大0.789だが、eventの82%を占めるroughの影響が大きい。stepのevent検出率は約43〜44%に留まる。 |
| stepとroughは単一1秒窓では区別しにくい | 支持 | 中央値には差があるが、窓単位balanced accuracyは約0.59〜0.61である。イベント単位では分離傾向が改善する。 |

元の仮説は全面的に誤っているわけではないが、`event` を一括りにしたことで、`rough` と `flat` の差が強調され、`step` と `flat` の重なりが隠れていた。

本分析から得られる、より適切な仮説は次の通りである。

> `rough` では `flat` より鉛直加速度の振幅が大きくなる傾向が比較的一貫している。一方、`step` は短時間の変化であり、約4 Hz・1秒窓ではピークを安定して捉えられず、`flat` と重なりやすい。`step` と `rough` は平均的な振幅と継続時間には差があるが、単一窓では不安定であるため、周囲窓とイベント継続時間を利用すると識別が改善する可能性がある。

## 6. 現時点の設計判断

現行の4特徴量だけで、直ちに `flat vs event`、次に `step vs rough` という2段階分類へ進む根拠は十分ではない。第1段階で `step` の約半数以上が `flat` 側へ落ちるため、第2段階を改善しても見逃した `step` は回復できない。

したがって、次の優先課題は分類器の複雑化ではなく、`step` の短時間変化と `rough` の持続性を表せる時間的文脈の検証である。

## 7. 次に行う時間的文脈の検証

### 7.1 時間的文脈を入れる目的

単一窓の振幅だけでなく、対象窓の前後がどのような状態かを特徴量にする。

- `step`: 周囲は比較的静かで、短時間だけ振幅が大きくなる可能性がある。
- `rough`: 周囲の複数窓でも振幅の大きい状態が持続する可能性がある。
- `flat`: 対象窓と周囲窓の両方で振幅が小さい可能性がある。

この違いを表現するには、「対象窓の強さ」「周囲の絶対的な強さ」「対象窓が周囲からどれだけ突出しているか」「高振幅状態が何秒続いたか」を分けて扱う必要がある。

### 7.2 比較する実験条件

| 実験 | 使用する情報 | 確認する目的 |
| --- | --- | --- |
| E0 | 現行の1秒窓・4特徴量 | 比較基準 |
| E1 | E0 + 前後1秒（±4窓）の文脈 | 短い時間文脈でstepの突出を捉えられるか |
| E2 | E0 + 前後2秒（±8窓）の文脈 | step周辺と短いroughの違いを捉えられるか |
| E3 | E0 + 前後3秒（±12窓）の文脈 | 継続時間中央値約5.9秒のroughを捉えられるか |
| E4 | 1秒・2秒・3秒窓の特徴量を併用 | 短時間衝撃と持続振動をマルチスケールで表せるか |
| E5 | 最良条件で連続event窓を結合し、イベント単位で分類 | 継続時間を明示的にstep/rough分類へ利用できるか |

0.5秒窓は約2サンプルしか含まないため、現データでは標準偏差やRMSが不安定になる。最初の比較対象には含めず、1秒窓を局所情報として残しながら、2秒・3秒の情報を追加する方が妥当である。

### 7.3 追加候補となる時間文脈特徴量

#### 周囲の絶対的な振動レベル

- 前後範囲における `z_std` または `z_rms` の平均
- 前後範囲における中央値
- 前後範囲における最大値

周囲も継続的に大きければ `rough`、周囲も小さければ `flat` と解釈できる可能性がある。

#### 対象窓の突出度

- 対象窓の `z_std` ÷ 周囲窓の `z_std` 中央値
- 対象窓の `z_rms` − 周囲窓の `z_rms` 中央値
- 対象窓と直前・直後窓との差

対象窓だけが周囲より大きければ、短時間衝撃である `step` の候補になる。

#### 持続性

- 周囲窓のうち高振幅と判定された窓の割合
- 高振幅窓が連続した数
- event候補の開始から終了までの推定継続時間

しきい値を用いる場合は、評価データを見て決めず、学習データ内だけで決定する。

現リポジトリには、`z_std_prev`、`z_std_next`、`z_std_ratio`、`z_std_neighbor_mean`、`z_std_neighbor_max` という前後約1秒の特徴量が既に実装されている。次の検証では、これらを一括して追加するだけでなく、E0とのアブレーション比較を行い、どの種類の時間情報が `step`、`rough` のどちらに効いたかを確認する。また、前後1秒だけでなく前後2秒・3秒へ範囲を広げた比較が必要である。

### 7.4 イベント単位の2段階処理

時間的文脈を使う場合、次の処理も候補となる。

1. 各1秒窓について、event候補となる確率またはスコアを出す。
2. 0.25〜0.5秒程度の短い途切れを許容しながら、連続するevent候補窓を1イベントへまとめる。
3. イベントの継続時間、`z_rms` の中央値・最大値、対象窓と周囲の比を計算する。
4. イベント単位で `step vs rough` を判定する。

ただし、現在の第1段階では `step` のevent検出率が約43%しかない。そのままイベント結合するとstep候補自体が消えるため、第1段階ではaccuracyを優先せず、stepのrecallを高く保つしきい値を検討する必要がある。その際、flatの誤検出数も同時に報告する。

### 7.5 評価方法

すべての実験で学習・評価条件を揃え、次の指標を比較する。

- 第1段階 `flat vs event`
  - `step` をeventとして検出したrecall
  - `rough` をeventとして検出したrecall
  - `flat` のspecificity
  - balanced accuracy、macro F1
- 第2段階 `step vs rough`
  - step recall、rough recall
  - balanced accuracy、macro F1
- イベント単位
  - イベントを1回でも検出できた割合
  - イベント単位のstep/rough分類結果
  - 継続時間の推定誤差

窓単位のaccuracyだけを採用判断に使わない。特に、E0に対してstep recallが改善したか、改善が6/22と7/12の両方で確認できるか、flatの誤検出が大幅に増えていないかを重視する。

交差検証では走行IDをグループとして固定し、同じ分割を全実験条件に使用する。標準化、しきい値、移動基準値などは学習側だけで決定する。また、前後窓の計算が別走行をまたがないようにする。

将来の情報を使う前後対称の文脈特徴は、オフライン分析では利用できるが、リアルタイム検出では結果が確定するまで1〜3秒の遅延が生じる。リアルタイム性が必要な場合は、同じ実験を過去方向のみの特徴量でも行う。

### 7.6 判断基準

- E1〜E4でstep recallがE0より安定して改善し、収集日別でも同じ傾向が得られた場合は、時間的文脈の追加を採用する。
- roughだけが改善しstepが改善しない場合は、`flat vs event` の2段階構成をそのまま採用しない。
- イベント単位でのみ `step vs rough` が改善する場合は、窓単位の3クラス分類ではなく、候補区間抽出後のイベント分類を採用候補とする。
- 窓幅や文脈範囲を変更してもstepがflatから分離しない場合は、約4 Hzのサンプリングでは短時間衝撃を十分に取得できていない可能性を考え、次回収集時のサンプリング周波数を見直す。

## 8. 結論

現行の基本特徴量では、`rough` と `flat` に比較的明確な分離傾向が見られた。一方、`step` は `flat` との重なりが大きく、`flat vs event` の第1段階で半数以上を見逃す可能性がある。また、`step` と `rough` は中央値には差があるものの、単一の1秒窓では安定した分類に至らなかった。

したがって、現時点では2段階分類器を確定するのではなく、1秒の局所特徴を残しながら前後1〜3秒の絶対振動レベル、突出度、持続性を追加し、走行単位の同一評価条件で比較することが妥当である。

発表用の結論を一文にすると、次のようになる。

> 現行特徴量ではroughとflatに分離傾向が見られた一方、stepはflatとの重なりが大きかったため、2段階分類へ進む前に、stepの短時間変化とroughの持続性を捉える時間文脈および窓設計を検証する必要がある。

# rough の再現率が 0.91 にとどまる原因と、ラベル・特徴量の直し方

ゼミ資料の core（z_rms・z_kurt・h_std・h_crest・tilt_range）・SVM・2.0 秒で、rough の再現率は 0.91 だった（flat 0.96、step 0.95）。何を何と間違えているかを調べ、原因が特徴量なのか、特定のセッション（測定）なのかを切り分けた。そのうえで、直し方を試した。

## サマリ

- **rough の間違い 37 窓のうち 27 窓（73%）が、`20261101143126` の 1 セッション**（凸凹の場所 D、69 kg）。このセッションの再現率は 0.78 で、ほかの凸凹は 0.94〜1.00。間違いの中身は、flat へ 13 窓、step へ 14 窓。
- **flat への間違いは、ラベルの区間の終わりの「もう揺れていない部分」**。
  - 揺れの終わり（z の包絡線が閾値を最後に超えた時刻）より後で、z_rms が flat 並みの窓が、143126 では 52 窓。ほかの凸凹（13〜25 窓）より多い。
  - 揺れの終わりから STOP までの時間（中央値）も、143126 が 1.24 秒で一番長い。同じ場所 D を 51 kg の人が走った `20261101142926` は 0.63 秒。場所ではなく、この測定のときの STOP の押し方によると考えられる。
- **step への間違いは、場所 D の路面の性質**。
  - 場所 D の凸凹は、車体が傾く大きめの凸がある。傾きの範囲の 90 パーセンタイルは 4.9 度で、同じ場所の 51 kg の人も 5.2 度。凸凹 ①（場所 A）の 3.4 度より大きい。
  - その窓では、tilt_range（4.7 度）が段差に寄る。一方で、「揺れが窓の中で続いている」という凸凹の性質は残っている。
- **判断：143126 は除かない**。step への間違いは、凸凹の 1 つの種類（大きめの凸がある凸凹）を表していて、学習に入れるべきデータ。flat への間違いは、このセッションだけでなく、凸凹の全部のセッションにある「STOP 側のラベルのずれ」の問題。
- **特徴量：水平の揺れの `h_burst_ratio`（短い時間の揺れの大きさの、最大 ÷ 中央値）を core に足すと、段差 ↔ 凸凹の区別そのものが良くなる**。

  | 特徴量 | 2.0 秒 flat / step / rough | 段差 ↔ 凸凹 | 1.0 秒 flat / step / rough | 段差 ↔ 凸凹 |
  | --- | --- | --- | --- | --- |
  | core | 0.96 / 0.95 / 0.91 | 39 | 0.91 / 0.87 / 0.83 | 181 |
  | **core + h_burst_ratio** | **0.96 / 0.97 / 0.92** | **25** | **0.91 / 0.89 / 0.86** | **138** |

  - flat は下がらない。セッションごとでは、2.0 秒で 5 上がって 2 下がり、1.0 秒で 9 上がって 2 下がった（16 セッション）。
  - 体重を入れ替えたテスト、日を入れ替えたテストでも、段差 ↔ 凸凹の取り違えは減るか同じ（4 章）。
  - 体重による値の変わり方は 0.90〜1.19 倍で、z_rms（1.13〜1.75 倍）より小さい。
- **ラベルの直し（凸凹の区間の終わりを揺れの終わりにする）は、分類の力を上げない**。rough は 0.91 → 0.95 になるが、静かな窓をテストから外した分だけ。どちらのラベルでも凸凹になる窓だけでテストすると、0.949 と 0.945 で同じ。
  - 揺れの終わりより後の窓を凸凹と呼ぶかは、ラベルの定義の問題として、別に決める必要がある（6 章）。
- **組み合わせ**（ラベルを直し、h_burst_ratio を足す）：2.0 秒で 0.95 / 0.97 / 0.97、段差 ↔ 凸凹 8 窓。
- **足す理由**
  - 物理：段差は 1〜2 回の衝撃の間が静か。凸凹は小さな凸が続くので、揺れが窓の中で続く。
  - このリポジトリの分析：10.5 の波形の観察で、同じ違いを見ている。
  - 関連研究：路面の凹凸を数えて悪路を判定する特許（US 6,859,703）。衝撃を含む振動では RMS だけでは足りないとする ISO 2631-1（二次資料で確認）。
- 9 個の候補から、同じ 16 セッションで選んだので、少し楽観的。各設定 1 回の評価。

### 4.3 なぜ効くのか（足す理由）

**物理的な根拠**

- 段差では、前輪・後輪が段の角に当たる 1〜2 回の衝撃があり、その間は静か。2.0 秒の窓の中で、揺れは一瞬に集中する。
- 凸凹では、小さな凸を次々に越えるので、揺れが窓の中で続く。大きめの凸が混ざっても（場所 D）、その前後の揺れは止まらない。
- `burst_ratio` は「窓の中のふだんの揺れ（中央値）に比べて、一番強い 30 ms がどれだけ突き出ているか」を表す。段差で大きく、凸凹・flat で小さい。揺れの大きさで割った比なので、体重の影響を受けにくい。

**このリポジトリの先行する分析**

- [10.5 の後ろ固定の分析](../2026-10-05/20261005_rear_only_analysis.md) の 5.3 節：波形を見て、「段差は約 4 秒おきに鋭い単発のバーストが出て、間は静か。凸凹は大きな振動が数秒続く」として、バースト系の特徴量を作った。
- [10.6 の寄与度](../2026-10-06/20261006_feature_importance_rear_only.md)：バースト系は、基本 4 の次に効く特徴量のグループだった。ゼミの構成（10.12 以降）では使っていなかったが、外した理由の記録は無い。

**関連研究**

- **路面の凹凸の数で悪路を判定する特許**：US 6,859,703 B2「Method and device for detecting a rough road section」（Continental Teves、J. Führer・U. Baiter、2005 年）。https://patents.google.com/patent/US6859703B2/en
  - 加速度がしきい値を一定時間以上超えたピークを、「段差（bump）か穴（pothole）に当たる単発のピーク」として数える。
  - 数が一定を超えると、悪路の区間と判定する。静かな時間が一定を超えると、数え直す。
  - 「単発の衝撃 = 段差・穴、続く凹凸 = 悪路」という区別そのもの。今回の特徴量は、数える代わりに、窓の中での突き出し方を比で表している。
- **ISO 2631-1（全身振動の評価の規格）**：規格の本文は未確認。二次資料で、次の 2 点を確認した。
  - クレストファクター（周波数補正した加速度の最大のピーク ÷ RMS）が 9 以下なら RMS で足り、9 を超えるなら VDV を勧める（Svantek の解説。https://svantek.com/applications/whole-body-vibration/ ）。
  - 1 秒の running RMS の最大値を MTVV（最大の過渡的な振動）とする。CF が 9 を超えると、基本の評価（RMS）では効率的に評価できない（Dewesoft の解説。https://dewesoft.com/blog/vehicle-ride-comfort-testing ）。
  - 衝撃を含む振動と続く振動は、RMS とは別の量（ピークと短い時間の RMS の関係）で区別する、という考え方の裏付け。`burst_ratio`（短い時間の RMS の最大 ÷ 中央値）は、これと同じ形の量。

**z ではなく h の版が効く理由**

- `z_burst_ratio` は、core の `z_kurt` と、順位相関が 0.96（68〜69 kg のラベル付きの窓）。z の「単発らしさ」は、尖度ですでに入っている。
- `h_burst_ratio` は、core の `h_crest` と 0.92、`z_kurt` と 0.85。h_crest と似ているが、次の違いがある。
  - クレストファクターは「最大のサンプル ÷ 窓の RMS」。大きな衝撃があると、RMS 自体がその衝撃で大きくなる。
  - burst_ratio は「30 ms の RMS の最大 ÷ 中央値」。中央値は衝撃にほとんど引っ張られないので、窓の大部分が静かか（段差）、揺れ続けているか（凸凹）が、そのまま出る。
- 段差で水平の衝撃が特に突き出る理由は、車輪が段の角に当たるとき、進む向きと逆向きの力（水平）が一瞬かかるためと考えられる（未検証）。

### 4.4 ラベルで分けて確かめる

どちらのラベル（5 章）でも凸凹になる窓（2.0 秒で 256 窓）だけでテストした。ラベルの付け方に左右されない、段差 ↔ 凸凹の区別の力。

| 窓 | 特徴量 | flat / step / rough | 段差 ↔ 凸凹 |
| --- | --- | --- | --- |
| 2.0 秒 | core | 0.956 / 0.948 / 0.949 | 28 |
| 2.0 秒 | core + h_burst_ratio | 0.957 / 0.966 / **0.977** | **14** |
| 1.0 秒 | core | 0.911 / 0.873 / 0.891 | 135 |
| 1.0 秒 | core + h_burst_ratio | 0.912 / 0.885 / **0.931** | **97** |

（学習は今のラベル。）

## 5. ラベル：凸凹の区間の終わりを「揺れの終わり」にする

| 窓 | 学習 | テスト | flat / step / rough | 段差 ↔ 凸凹 | rough → flat | 凸凹の窓 | 143126 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 2.0 秒 | 今のラベル | 今のラベル | 0.956 / 0.948 / 0.909 | 39 | 15 | 408 | 0.777 |
| 2.0 秒 | 揺れの終わりまで | 揺れの終わりまで | 0.955 / 0.951 / 0.945 | 22 | 3 | 256 | 0.867 |
| 2.0 秒 | 揺れの終わりまで | 今のラベル | 0.955 / 0.951 / 0.848 | 46 | 27 | 408 | 0.645 |
| 2.0 秒 | 今のラベル | 共通の窓 | 0.956 / 0.948 / 0.949 | 28 | | 256 | |
| 2.0 秒 | 揺れの終わりまで | 共通の窓 | 0.955 / 0.951 / 0.945 | 22 | | 256 | |
| 1.0 秒 | 今のラベル | 今のラベル | 0.911 / 0.873 / 0.828 | 181 | 44 | 813 | 0.681 |
| 1.0 秒 | 揺れの終わりまで | 揺れの終わりまで | 0.930 / 0.877 / 0.883 | 118 | 12 | 521 | 0.769 |

- 揺れの終わりまでにすると、凸凹の窓が 408 → 256 に減り、rough は 0.95 になる。rough → flat は 15 → 3 窓。
- ただし、**共通の窓でテストすると、学習のラベルを変えても 0.949 → 0.945 で変わらない**。上がったのは、静かな窓をテストから外したため。
- 学習だけ揺れの終わりまでにして、今のラベルでテストすると、0.85 に下がる。モデルが「凸凹 = 揺れ続けている」と覚えるので、終わりの静かな窓を flat と答える。
- 揺れの終わりより後の窓は、z の包絡線が flat の 99 パーセンタイルを一度も超えない部分。そこが本当に凸凹の路面かは、データからは確かめられない（動画などが要る）。凸凹の上でも、ゆっくり走れば静かになりうる。
- 揺れが一度も閾値を超えない通過（揺れの弱い凸凹。143126 の #6 など）は、この方法では通過ごと外れる。弱い凸凹を評価から外すことになるので、この点は直す必要がある。

## 6. 結論と提案

1. **core に `h_burst_ratio` を足す**（仮に core + h_burst_ratio）。
   - 理由：4.3 節（物理、10.5 の観察、特許・ISO 2631-1 の考え方）。
   - 結果：段差 ↔ 凸凹の区別そのものが良くなる（共通の窓で、rough 0.949 → 0.977）。体重・日を入れ替えても悪くならない。
2. **143126 は除かない**。場所 D の凸凹は、実際の道にもある「大きめの凸がある凸凹」で、学習に必要。
3. **凸凹の STOP 側のラベルは、決め方を決める必要がある**。
   - 揺れの終わりで切ると、rough の数字は 0.97 まで上がる（h_burst_ratio と組み合わせて、2.0 秒）。ただし、分類の力ではなく、評価の定義が変わるだけ。
   - 採るなら、全部の凸凹のセッションに同じ規則で当てはめる。揺れが一度も閾値を超えない通過の扱いも決める。
   - 次の測定では、凸凹を抜けたらすぐ STOP を押す（または、凸凹の区間の終わりに目印を置く）と、この問題自体が小さくなる。

組み合わせ（2.0 秒）：

| ラベル | 特徴量 | flat / step / rough | 段差 ↔ 凸凹 |
| --- | --- | --- | --- |
| 今のラベル | core | 0.956 / 0.948 / 0.909 | 39 |
| 今のラベル | core + h_burst_ratio | 0.957 / 0.966 / 0.924 | 25 |
| 揺れの終わりまで | core | 0.955 / 0.951 / 0.945 | 22 |
| 揺れの終わりまで | core + h_burst_ratio | 0.952 / 0.972 / 0.969 | 8 |

## 7. 限界

- h_burst_ratio は、9 個の候補から、同じ 16 セッションの LOGO で選んだ。体重・日を入れ替えたテストで確かめたが、同じセッションの組み替えで、新しいデータではない。
- 凸凹は 4 セッション（場所は 10.31 と 11.1 の数か所）。場所 D のような凸凹が、ほかにどれだけあるかは分からない。
- 段差で水平の衝撃が突き出る理由（4.3 節の最後）は、確かめていない。
- ISO 2631-1 は、規格の本文ではなく、解説ページで確認した。MTVV/aw などの比の基準値は、確認できなかったので書いていない。
- 各設定 1 回の評価。

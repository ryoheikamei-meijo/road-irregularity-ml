# 体重によらない周波数帯の特徴量を、ゼミの core で確かめ直す

[体重・車椅子によらない周波数帯の特徴量](../2026-11-01/20261101_band_features.md)（11.1）では、core5（z_rms・z_kurt・tilt_range・g_low_high・g_over_z）の z を 8〜16 Hz 版にした core5b で、51 kg → 68〜69 kg の rough が 0.89 → 0.97 になった。

ゼミ資料（131-017）の core（暫定）は、z_rms・z_kurt・h_std・h_crest・tilt_range で、core5 とは中身が違う。前回のゼミの「今後の方針 1」（体重に依存する特徴量を、依存しない形に置き換える）の報告にするため、次の 3 つを行った。

- 発想と関連研究を整理し直す（1 章）。
- 関連研究を、本文・要旨で確かめ直す（2 章）。
- ゼミの core で検証し直す（3〜5 章）。

## サマリ

- **発想**：体重による揺れの変わり方は、路面ごとに違った（flat 約 1.2 倍、凸凹 約 1.45 倍）。そのため、「揺れの大きさを 1 つの数で割る」補正は効かなかった。基礎の振動理論では、固有振動数より十分低い揺れは、重さによらず地面の揺れがそのまま車体に伝わる。そこで、その帯域だけを使えば、体重によらない特徴量になると考えた。
- **関連研究**
  - 車椅子の振動は、荷重（人・ダミー・空）で周波数の中身と大きさが変わる（Larivière ら 2023）。
  - 路面推定の分野では、車両の伝達関数を同定して取り除くのが主流（11.1 の調査）。ただし、決まった段差を走るなどの較正が要る。
  - この研究では、伝達関数を同定する代わりに、伝達率がほぼ 1 になる帯域だけを使う。較正が要らない。帯域を選んで重さによらなくする前例は、見つけられなかった。
- **信号の段階では、見立てどおり**：同じ場所の 51 kg ÷ 69 kg の振幅の比は、上下の揺れで、8〜16 Hz が 0.65〜1.17、16〜32 Hz が 0.92〜4.04。体重の差は、固有振動数の付近に集中している。
- **特徴量の段階でも、体重の差は 1/2〜1/6 になる**：体重による差（標準化した単位）は、z_rms 0.34 → 0.06、z_kurt 0.21 → 0.10。クラスを区別する力はほぼ変わらない。
- **ただし、ゼミの core では、精度は上がらなかった**（SVM・2.0 秒、flat / step / rough）。

  | 特徴量 | 同じ人の中 | 51 → 68〜69 kg | その上限 | 68〜69 → 51 kg |
  | --- | --- | --- | --- | --- |
  | core | 0.96 / 0.95 / 0.91 | 0.96 / 0.97 / 0.88 | 0.96 / 0.96 / 0.90 | 1.00 / 0.98 / 0.97 |
  | core（z を 8〜16 Hz 版） | 0.89 / 0.94 / 0.88 | 0.96 / 0.91 / 0.89 | 0.92 / 0.93 / 0.89 | 0.95 / 0.97 / 0.99 |

  - ゼミの core では、体重の問題がもともと小さい。51 → 68〜69 kg の rough は 0.88 で、上限（0.90）との差は 0.02 しかない。帯域版にしても 0.89。
  - 1.0 秒の窓では、51 → 68〜69 kg の rough が 0.78 → 0.83（上限 0.84）に上がる。
  - 代わりに、同じ人の中の flat が 0.96 → 0.89 に下がる。路面の粗い flat（`20261031150048`、`20261101143455`）を凸凹と間違える。粗い flat と凸凹を見分ける手がかりが、捨てた固有振動数の帯域にあるため（11.1 の 3 章と同じ）。
- **水平の揺れには、同じ考え方が使えない**。水平の 8〜16 Hz の比は 0.83〜1.76 で、体重によらない帯域がない。水平も帯域版にすると、68〜69 → 51 kg の rough が 0.97 → 0.86 に下がる。
- **判断：今の core（暫定）は置き換えない**。体重に強い特徴量は作れたが、2 人・体重差 18 kg の今のデータでは、精度の利点が出ない。flat を見分ける力が落ちる分のほうが大きい。重りを足す測定（[計画](../2026-11-02/20261102_load_measurement_plan.md)）で、体重差が大きい条件で確かめ直す。

## 1. 発想

1. **前回のゼミ（131-017）の 7 章**：51 kg で学習して 68 kg でテストすると、rough が 0.88 に下がった。core のうち、z_rms の体重の影響が大きく、z_kurt・h_std が中くらいだった。
2. **1 つの数で割る補正は効かなかった**（[補正の評価](../2026-11-01/20261101_correction_eval.md)、[人ごとの平坦路の基準](../2026-11-01/20261101_person_calib.md)）。体重による揺れの倍率が、flat で約 1.2 倍、凸凹で約 1.45 倍と、路面ごとに違ったため。
3. **見立て（物理的な根拠）**：車椅子 + 人を、地面が揺れる「質量 + ばね + ダンパー」とみなす。車体の揺れ ÷ 地面の揺れ（伝達率）は、次の式になる（2 章の [1]）。

   X / Y = √[(1 + (2ζr)²) / ((1 − r²)² + (2ζr)²)]　（r = 揺れの周波数 ÷ 固有振動数、ζ = 減衰比）

   - 体重（質量）は、固有振動数と減衰比を通してしか入らない。
   - r が小さい（揺れの周波数が固有振動数より十分低い）と、伝達率は 1 に近づく。つまり、重さによらず、地面の揺れがそのまま伝わる。
   - 体重が変わって大きく変わるのは、固有振動数の付近（r ≈ 1）とそれより上。
4. **この研究への落とし込み**：上下の揺れ z を、汎用の車椅子の固有振動数（11.1 の [形だけの補正](../2026-11-01/20261101_spectral_shape.md) で 15〜30 Hz）より低い帯域に絞ってから、z_rms・z_kurt を計算する。フィルタを 1 回かけるだけで、較正（平坦路を走る、体重を入力する）は要らない。

### この研究の位置づけ

- 振動が荷重（重さ）で変わることは、車椅子でも（[2]）、地形の分類でも（Coyle ら 2011）知られている。
- 路面推定では、車両の伝達関数を同定して取り除く方法が主流（iDRIMS、SmartRoadSense）。ただし、決まった段差を走る・基準の走行をするなどの較正が要る。
- この研究では、伝達関数を同定する代わりに、**伝達率が重さによらず 1 に近い帯域だけを使う**（[1] の式）。較正が要らない。
- 「帯域を選んで重さによらなくする」前例は、11.1 と今回の調査では見つけられなかった。関連研究を組み合わせて、この研究で試した方法と言うのが正確。

### 固有振動数を、学習に使う人のデータだけから決められるか

| セッション | 山の周波数 [Hz] |
| --- | --- |
| 20261031150048・20261031152608（10.31） | 30.0・29.5 |
| 20261101141253・143455・143609・143706（11.1） | 57.4・57.9・59.5・52.7 |

- 代わりに、帯域の上限を変えていったときの精度を見た（4 章）。

### 4.4 結果の読み方

- **ゼミの core では、体重の問題がもともと小さい**。2.0 秒の 51 → 68〜69 kg の rough は 0.88 で、上限（0.90）との差は 0.02。68〜69 → 51 kg は 0.97 で、上限（0.98）とほぼ同じ。帯域版で取り戻せる余地が、ほとんどない。
- 11.1 の core5 では、51 → 68〜69 kg の rough が 0.89 で、上限 0.93 との差があった。ゼミの core には、core5 に無い h_std（水平の揺れの大きさ）がある。h_std は体重による差が 0.12 と小さく（5 章）、揺れの大きさの手がかりを、z_rms より体重の影響を受けにくい形で持っている。このため、ゼミの core は、もともと体重に強くなっていると考えられる（確かめていない）。
- **帯域版では、同じ人の中の flat が下がる**（2.0 秒で 0.96 → 0.89）。

  | flat のセッション | core | z を 8〜16 Hz |
  | --- | --- | --- |
  | 20261031150048（路面の粗い flat） | 0.94 | **0.78** |
  | 20261101143455（路面の粗い flat） | 0.95 | **0.81** |
  | ほかの 4 セッション | 0.91〜1.00 | 0.94〜1.00 |

  - flat → rough は 21 → 67 窓。粗い flat と、揺れの弱い凸凹は、8〜16 Hz の揺れの大きさが同じくらいで、見分ける手がかりの一部が固有振動数の帯域にある。11.1 の 3 章（inv5 で精度が下がる理由）と同じ。
- 1.0 秒では、51 → 68〜69 kg の rough が 0.78 → 0.83 に上がり、上限（0.84）に近づく。短い窓では、体重の影響が出やすく、帯域版の効果が見える。

| tilt_range | 0.13 | 0.71 | 1.42 | 0.72 |

- z_rms・z_kurt は、帯域版にすると、体重による差が 1/2〜1/6 になる。クラスを区別する力（flat ↔ 凸凹、flat ↔ 段差、段差 ↔ 凸凹）は、ほぼ変わらない。
- 「flat ↔ 凸凹」の差は、窓のクラスの中央値の差なので、粗い flat と弱い凸凹のような、重なる部分の区別は表さない。4.4 の flat の低下は、この表には出ない。
- h_std・h_crest は、もともと体重による差が小さい（0.12）。

## 6. 考察とゼミでの話し方

- 見立て（固有振動数より低い帯域は体重によらない）は、信号の段階（3 章）と特徴量の段階（5 章）では確かめられた。
- ただし、ゼミの core では、精度の利点が出なかった。
  - ゼミの core は、もともと体重に強い（51 → 68〜69 kg の rough 0.88、上限 0.90）。
  - 帯域を絞ると、粗い flat を見分ける手がかりも捨てる（flat 0.96 → 0.89）。
- **話し方の案**：
  1. 前回の課題：z_rms などが体重に依存し、51 → 68 kg で rough が 0.88 に下がった。
  2. 発想：基礎の振動理論の伝達率（[1]）。固有振動数より低い帯域では、重さによらず地面の揺れがそのまま伝わる。関連研究（[2]、iDRIMS など）は較正で車両の応答を取り除くが、較正の要らない方法として、帯域を絞る方法を試した。
  3. 確かめた：体重の差は 16〜32 Hz に集中し、8〜16 Hz は 0.65〜1.17 倍。z_rms の体重による差は 0.34 → 0.06。
  4. 結果：今の core では、精度の差はほとんど無かった。ゼミの core は h_std などを含み、もともと体重の影響が小さい（上限との差 0.02）。代わりに、粗い flat の区別が落ちる。
  5. 今後：重りを足す測定（体重差を大きくする）で、帯域版が効く条件があるかを確かめる。今の core は置き換えない。

## 7. 限界

- 体重は 2 人（51 kg と 68〜69 kg）、同じ場所の組は 6 組。体重差は 18 kg。
- 8〜16 Hz という帯域は、11.1 で、テストに使うのと同じ組の比を見て決めた。今回、学習に使う人のデータだけから固有振動数を決めようとしたが、スペクトルの山が日によって違い、決められなかった（3 章）。
- 速度は測っていない（[143126 の確認](../2026-11-07/20261107_session_143126_check.md) の 4 章）。速度が変わると、路面の凹凸が揺れの周波数に変わる関係（空間周波数 × 速度）がずれ、帯域の効き方が変わる可能性がある。
- 関連研究の [2]・[3] は要旨までの確認。
- 各設定 1 回の評価。

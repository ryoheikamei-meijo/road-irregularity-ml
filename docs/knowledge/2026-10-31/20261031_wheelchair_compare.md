# 2 台の車椅子で加速度に差があるか（10.31）

10.31 の測定では、元々使っていた車椅子（**従来**、`original`）に加えて、新しく買った汎用の車椅子（**汎用**、`standard`）でも測った。従来の車椅子は、汎用のものと性質が離れているかもしれない。加速度がだいたい同じなら混ぜて学習し、明らかに違うなら除いて学習する、という方針（測定者の指示）で比べた。

## サマリ

- **凸凹では、従来の車椅子の揺れが明らかに大きい**。z の rms は 1.6〜1.9 倍で、2 組のペアの両方で、通過ごとの値が汎用とまったく重ならない（Cliff の δ = 1.00）。揺れている時間も長い（1.55 → 2.70 秒、2.67 → 4.51 秒）。
- **段差では、差は小さいか、ペアによって違う**。z の rms は 1.03 倍と 1.16 倍。ただし、**揺れている時間は、従来のほうが 2 倍ほど長い**（0.42 → 1.07 秒、0.70 → 1.42 秒）。
- ボタンの区間の長さ（≒ 通過にかかった時間）は 2 台でほぼ同じなので、押す速さの違いだけでは説明しにくい。
- **判断：明らかに違うので、従来の車椅子は混ぜない**。10.31 の評価（[ボタンのラグ](20261031_button_lag_eval.md)）は、汎用だけで行う。混ぜた場合も参考に出している。
- 参考：汎用だけで学習したモデルで従来の窓を予測しても、再現率は下がらなかった（凸凹はかえって上がる）。従来の揺れが大きく、凸凹らしく見えるため。モデルの上では混ぜても困らないが、加速度そのものが違うので、上の判断は変えない。

## 0. 方法

### データ

`configs/sessions/10.31.csv`。続けて測ったセッションは同じ路面（測定者に確認）なので、そのペアで直接比べた。

| ペア | 種類 | 汎用 | 従来 |
| --- | --- | --- | --- |
| 段差① | step | 20261031142102 | 20261031142344・20261031142508 |
| 凸凹① | rough | 20261031143004 | 20261031142814 |
| 段差② | step | 20261031144423 | 20261031144130 |
| 凸凹② | rough | 20261031145017 | 20261031145240 |

- **`20261031144130` は、アプリでは汎用として記録したが、実際は従来の車椅子**（記録ミス。測定者に確認済み）。`configs/sessions/10.31.csv` を直してある。
- 従来の車椅子では flat を測っていない。

### 比べたもの

通過ごとに、次を計算した（`pass_stats.csv`）。「揺れている区間」は、z の 100ms RMS 包絡線が、汎用の flat セッションの包絡線の 99 パーセンタイル（約 8.3 m/s²）を超えている、最初から最後まで（[ボタンのラグ](20261031_button_lag_eval.md) と同じ）。

- 揺れている区間の、z と水平の大きさ h = √(x² + y²) の rms・ピーク、z の尖度
- 車椅子自体の振動として、START から揺れ始めまで（段差・凸凹に着く前の平坦な走行）の z・h の rms

違いの大きさは、中央値の比（従来 / 汎用）と、Cliff の δ（従来のほうが大きい確率 − 小さい確率。|δ| ≥ 0.47 で大きな差とされる）で見た。

## 2. 考察

- 凸凹の揺れの違いは、2 組のペアの両方で、通過ごとの値が重ならないほど大きく、偶然とは考えにくい。同じ路面なので、車椅子の違い（タイヤ・キャスター・フレーム・サスペンションなど）によると考えられる（どの部品の違いかは、データからは分からない）。
- 段差で「従来は衝撃のあとの揺れが長く続く」のは、[10.17 の step → rough の原因](../2026-10-17/20261017_step_rough_error_causes.md)（段差の通過で揺れが長く続く 2 セッション）と似ている。10.3・10.4 は従来の車椅子で測っている。10.17 では「乗り越える」通過が原因と考えたが、**車椅子そのものの揺れ方も効いていた可能性がある**（推測。確かめていない）。

## 3. 限界

- ペアは 4 組で、同じ日・同じ人の測定。押す速さは測っていない（ボタンの区間の長さで代わりに見ただけ）。
- 「揺れている区間」の閾値は、汎用の flat から決めている。従来は揺れが大きいので、揺れ始めが早めに判定される（START → 揺れ始めのラグが、従来のほうが短く出る）。
- 従来の flat が無いので、車椅子自体の振動（平坦な走行）は、着く前の短い区間でしか比べられていない。
